# Timeline Forensic Analyzer

A digital forensics tool for file integrity 
verification and timeline analysis.

## Features
- MD5 hash computation per file
- Last modified timestamp extraction
- Forensic timeline report generation
- Folder scanning

## Tech Stack
- C++
- OpenSSL (MD5)
- std::filesystem
